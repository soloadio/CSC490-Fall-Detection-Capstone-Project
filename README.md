# CSC490-Fall-Detection-Capstone-Project

Fall detection on the OmniFall datasets (EDF, MCFD, UP-Fall), and a live multi-camera demo app.

- `research/`: data preparation, training and evaluation, one folder per part (see `research/README.md`). Results are written up in `research/results/`.
- `research/splits/`: the team's train / val / test split lists. Files that `research/splits/README.md` mentions but are not here (`frames32_*`, `up_fall_events_*`) are generated by the scripts it lists.
- `app/`: the Gradio app (VideoMAE alarm, multi-camera rooms, push alerts, optional vision-language second opinion in `verifier.py`).
- `tests/`: scripts that run the app's real handlers on replayed recordings.

Not in git: datasets, extracted frames and model weights. Scripts contain paths from the Alliance Fir cluster (`/scratch/wuhungma/...`, `/project/6010122/group12/...`); change them to run elsewhere.
